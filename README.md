**CyberShield – Cyber Security Awareness Platform**



**1. Introduction**



CyberShield is a web-based cybersecurity awareness platform designed to help users identify potentially suspicious messages and URL warning signs. It also provides cyber safety tips and an awareness quiz.



**2. Problem Statement**



Users frequently receive suspicious messages involving fake prizes, urgent account warnings, OTP requests, and payment demands. CyberShield aims to help users recognise these warning signs.



**3. Objectives**



\* Identify predefined suspicious patterns in messages.

\* Check URLs for potentially suspicious characteristics.

\* Provide cyber safety tips.

\* Improve cybersecurity awareness through a quiz.



**4. Technologies Used**



\* HTML

\* CSS

\* JavaScript

\* Visual Studio Code

\* GitHub



**5. Core Features**



\* Scam Message Detector



Checks user-provided messages against predefined scam-related patterns and displays a rule-based risk score.



\* Suspicious URL Checker



Examines selected URL characteristics and displays relevant warning signs.



\* Cyber Safety Tips



Provides basic guidance for safer online behaviour.



\* Cyber Safety Quiz



Tests users' understanding of cybersecurity through a short quiz.



**6. How to Run the Project**



1\. Download or clone this repository.

2\. Open the project folder.

3\. Open `index.html` in a web browser.

4\. Test the message checker, URL checker, and quiz.



**7. Current Implementation**



The current prototype uses predefined rules and JavaScript logic. It does not use a trained machine learning model or a real-time threat intelligence database.



**8. Limitations**



\* Some legitimate messages may be flagged as suspicious.

\* New scam patterns may not be detected.

\* URL checks do not confirm whether a website is malicious.

\* Risk scores are indicators, not verified probabilities.



**9. Future Enhancements**



\* Add more detection rules.

\* Improve input validation and error handling.

\* Explore integration with a trusted threat intelligence API.

\* Explore machine learning-based message classification.
